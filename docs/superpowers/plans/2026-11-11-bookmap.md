# bookmap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build bookmap v1: annotations, a JavaPoet annotation processor that generates book codecs, a client with validation and automatic continuation, an in-memory simulator transport, and a Spring Boot auto-configuration.

**Architecture:** `bookmap-core` contains the annotations, the public API, and a runtime library of conversions (`BookWriter`, `BookReader`). The processor parses `pic` strings, applies the conventions and `@BookDefaults`, and generates one `<Class>_BookCodec` for each `@BookOperation` class. The generated code calls only the runtime library and the getters and setters of the POJO (no reflection). `BookCodecRegistry` finds the codecs with `ServiceLoader`. Transports implement a byte-level SPI.

**Tech Stack:** Java 21 (toolchain), Gradle 9.9.1 (Kotlin DSL, version catalog), JavaPoet (`com.palantir.javapoet:javapoet`), JUnit Jupiter, AssertJ, Google compile-testing, Lombok (examples only), Spring Boot 4.0.x (`bookmap-spring-boot` only).

**Spec:** `docs/superpowers/specs/2026-11-10-bookmap-design.md`

## Global Constraints

- Java 21 toolchain. Gradle with Kotlin DSL and `gradle/libs.versions.toml`.
- Base package `pt.daaz.bookmap`.
- `bookmap-core` has no runtime dependencies other than the JDK. `bookmap-processor` depends only on `bookmap-core` and JavaPoet.
- No reflection at runtime. The generated code uses getters, setters, and `new`.
- All code, comments, Javadoc, messages, and documentation are in English. Documentation follows ASD-STE100 for approximately 80% (see `CLAUDE.md`).
- Examples and test data use an international domain (orders, invoices, shipments, customers). Do not use CPF, CNPJ, or NIF.
- All exceptions are unchecked and extend `BookmapException`.
- A mapping error message identifies the class, the field, and the `order`, in the format `"<SimpleClassName>.<field> (order <n>): <problem>"`.
- Default charset: `IBM037`. Default `maxCalls`: 1000.
- Never truncate or round silently. A value that does not fit causes `MappingException`.
- Only single-byte charsets. `CodecContext` rejects a charset with `newEncoder().maxBytesPerChar() > 1`.
- **Coverage: 100% line and branch coverage** of production code in `bookmap-core`, `bookmap-processor`, `bookmap-transport-simulator`, and `bookmap-spring-boot` (JaCoCo, `jacocoTestCoverageVerification`, `check` depends on it). Do not use exclusions to reach the number. Each task ends with `./gradlew :<module>:check` green.
- Tests use AssertJ. For compile-testing, call `CompilationSubject.assertThat(compilation)` without a static import, so that it does not clash with AssertJ.

## Review Focus

1. **Text characters that the charset cannot encode** (for example, `"Müller"` is fine in IBM037, but `"東京"` is not): expect `MappingException`, not a silent `?`. Test in Task 2.
2. **Malformed numeric or date bytes in a response** (a letter in a zoned field, an invalid packed nibble, `20261340` as a date): expect `MappingException` with the field descriptor, not `NumberFormatException` or `DateTimeParseException`. Tests in Tasks 2, 3, 4.
3. **A response count field that is blank, negative, or more than `maxOccurs`**: blank means 0 items. More than `maxOccurs` causes `MappingException`. Test in Task 9.
4. **A `BigDecimal` with more scale but the same value** (`10.500` into `V99`): expect success. `10.505` into `V99`: expect `MappingException`. Test in Task 2.
5. **A transport that returns `null`**: expect `MappingException("... empty response ...")`, not `NullPointerException`. Test in Task 5.

**Interfaces:**
- Produces:
  - `@BookOperation { String value() default ""; }` — `@Target(TYPE)`, `@Retention(CLASS)`. Empty means "simple class name".
  - `@BookField { int order(); String pic() default ""; int length() default 0; Direction direction() default INPUT_OUTPUT; Usage usage() default DISPLAY; int scale() default 0; boolean signed() default false; String pattern() default "yyyyMMdd"; Class<? extends FieldConverter> converter() default NoConverter.class; }` — `@Target(FIELD)`, `@Retention(CLASS)`. The processor decides "explicitly set" through `AnnotationMirror.getElementValues()`, not through the default values.
  - `@BookCollection { int order(); Direction direction() default OUTPUT; String dependsOn() default ""; int maxOccurs(); }` — `@Target(FIELD)`, `@Retention(CLASS)`.
  - `@BookDefaults { String charset() default ""; Usage usage() default DISPLAY; boolean signed() default false; String pattern() default "yyyyMMdd"; }` — `@Target({TYPE, PACKAGE})`, `@Retention(CLASS)`. Only explicitly set attributes override lower levels.
  - `enum Direction { INPUT, OUTPUT, INPUT_OUTPUT; boolean isInput(); boolean isOutput(); }`
  - `enum Usage { DISPLAY, COMP3, COMP }`
  - `interface Continuable { boolean hasContinuation(); }`, `interface Validatable { void validate(); }`
  - Exceptions as in spec 5.10. Each has `(String message)` and `(String message, Throwable cause)` constructors, except `RemoteAbendException`: it has `(String abendCode, String message)` and `(String abendCode, String message, Throwable cause)`, and `String abendCode()`.
  - `interface Transport { byte[] exchange(BookRequest request); }`
  - `record BookRequest(String operation, byte[] payload, int maxResponseLength, Map<String,String> attributes)` — the compact constructor requires non-null `operation` and `payload` and replaces a null `attributes` with `Map.of()`. It also has a 3-argument constructor without `attributes`.
  - `record CodecContext(Charset charset)`, with `static CodecContext defaults()` that returns IBM037. The compact constructor rejects `null` and multi-byte charsets (`IllegalArgumentException`).
  - `interface BookCodec<T>`: `Class<T> type(); String operationName(); String charsetName(); int maxResponseLength(); T newInstance(); byte[] encodeRequest(T value, CodecContext ctx); void decodeResponse(byte[] data, T target, CodecContext ctx); T decodeRequest(byte[] data, CodecContext ctx); byte[] encodeResponse(T value, CodecContext ctx); void resetOutputCollections(T value);`
  - `interface FieldConverter<J> { J decode(byte[] bytes, FieldContext context); byte[] encode(J value, FieldContext context); }`
  - `record FieldContext(String field, int length, int scale, boolean signed, Usage usage, String pattern, int byteLength, Charset charset)`
  - `final class NoConverter implements FieldConverter<Object>` (a marker. Both methods throw `UnsupportedOperationException`.)

**Files:**

**Interfaces:**
- Consumes: `CodecContext`, `Usage`, `MappingException` (Task 1).
- Produces:
  - `final class BookWriter { BookWriter(CodecContext ctx); void writeText(String field, String value, int length); void writeNumber(String field, BigDecimal value, int length, int scale, boolean signed, Usage usage); byte[] toByteArray(); }`
  - `final class BookReader { BookReader(byte[] data, CodecContext ctx); String readText(String field, int length); BigDecimal readNumber(String field, int length, int scale, boolean signed, Usage usage); int position(); }`
  - `field` is the descriptor string `"<Class>.<field> (order <n>)"`. Each error message starts with it.
  - `public static int byteLength(Usage usage, int length)` in `BookWriter` (DISPLAY → length, COMP3 → length/2+1, COMP → 2/4/8 for 1–4/5–9/10–18 digits). The processor uses the same rule.
  - `Blank.isBlank(byte[] bytes, int from, int len, Charset cs)` → true if all bytes are the charset space or `0x00`.

Rules (spec 5.3): text pads with spaces on the right. Text read changes `0x00` to space, removes spaces on the right, and never returns `null`. Encode text with a `CharsetEncoder` with `CodingErrorAction.REPORT`. Zoned decimal (spec 5.3): detect EBCDIC with `"0".getBytes(cs)[0] == (byte) 0xF0`. For EBCDIC, work on bytes: digit `0xF0 | d`; for a signed field, last byte `0xC0 | d` (positive) or `0xD0 | d` (negative). On read, zones `C`, `F`, `A`, `E` are positive and `D`, `B` are negative. For an ASCII charset, use the overpunch characters `{ABCDEFGHI` / `}JKLMNOPQR` for the last digit. An unsigned field accepts zone `C` in the last byte and rejects zone `D`. A null number writes zeros. A blank read returns `null`. `writeNumber` uses `value.setScale(scale, RoundingMode.UNNECESSARY)` and catches `ArithmeticException` into `MappingException`. A short buffer in `BookReader` causes `MappingException` with the text "response too short".

### Task 3: Packed (COMP-3) and binary (COMP) conversions

**Files:**
- Create: `bookmap-core/.../codec/internal/PackedDecimal.java`, `BinaryInteger.java`
- Modify: `BookWriter.writeNumber`, `BookReader.readNumber` (delegate on `Usage.COMP3` and `Usage.COMP`)
- Test: `bookmap-core/src/test/java/pt/daaz/bookmap/codec/PackedAndBinaryTest.java`

**Interfaces:**
- Consumes: `BookWriter`, `BookReader` (Task 2).
- Produces: no new public API. `writeNumber` and `readNumber` support all `Usage` values.

Rules: packed sign nibble `C` positive, `D` negative, `F` unsigned. Read accepts `A`, `C`, `E`, `F` as positive, `B`, `D` as negative. An even `length` gets a leading zero nibble. Binary is big-endian, two's complement when signed. On write, the value must have at most `length` digits (as COBOL `TRUNC(STD)`). On binary read, accept every value that fits in the byte size (hosts with `TRUNC(BIN)`). A packed read of all `0x00` or all charset spaces returns `null`. A binary read never returns `null`: all `0x00` is 0.

### Task 5: Codec registry and client execution cycle

**Files:**
- Create: `bookmap-core/.../codec/BookCodecRegistry.java`, `bookmap-core/.../BookmapClient.java`
- Test: `bookmap-core/src/test/java/pt/daaz/bookmap/BookmapClientTest.java`, `bookmap-core/src/test/java/pt/daaz/bookmap/codec/BookCodecRegistryTest.java`

**Interfaces:**
- Consumes: `BookCodec`, `Transport`, `BookRequest`, `CodecContext`, `Continuable`, `Validatable`, exceptions.
- Produces:
  - `final class BookCodecRegistry { static BookCodecRegistry loadDefault(); static BookCodecRegistry loadDefault(ClassLoader loader); static BookCodecRegistry of(BookCodec<?>... codecs); <T> BookCodec<T> codecFor(Class<T> type); }` — `codecFor` throws `MappingException` with the text `"No codec for <FQCN>. Make sure that bookmap-processor is on the annotationProcessor path."`
  - `final class BookmapClient { static Builder builder(); <T> T execute(T request); }`
  - `BookmapClient.Builder { transport(Transport); charset(Charset); maxCalls(int); codecRegistry(BookCodecRegistry); build(); }` — `transport` is mandatory. `maxCalls` must be ≥ 1. The default registry is `loadDefault()`.

Charset: if `codec.charsetName()` is not empty, use a `CodecContext` with that charset for this codec. Else use the default context. The client makes the default context in `build()` and keeps a `ConcurrentHashMap` cache for codec charsets. `codecFor` uses the exact class (spec 5.8).

Cycle (spec 5.8): codec lookup → `resetOutputCollections` → loop { `encodeRequest` → `transport.exchange(new BookRequest(op, payload, codec.maxResponseLength()))` → null response → `MappingException("<op>: empty response from transport")` → `decodeResponse` → `validate()` if `Validatable` → `hasContinuation()` if `Continuable` }. Count calls. When a further call would be call number `maxCalls + 1`, throw `ContinuationLimitException`.

Use hand-written test codecs in the tests (a `FakeCodec` for a small test POJO). Do not use the processor here.

Do not keep `TypeMirror` or `TypeElement` after the compilation.

Convention resolution (spec 4.12 and 5.2), in this sequence:
1. Operation name: the `@BookOperation` value, or the simple class name if the value is empty.
2. Charset: `@BookDefaults` charset of the operation class or its package, else `""`. An unknown or multi-byte charset is a compile error. A different explicit `charset` in `@BookDefaults` of a superclass or item class (or their packages) is a compile error.
3. For each field, take each attribute from: the explicit attribute → `pic` (for `length`, `scale`, `signed`, `usage`) → `ResolvedDefaults` of the declaring class → the built-in default. The `usage` and `signed` defaults apply **only** to numeric Java types (`int`, `Integer`, `long`, `Long`, `BigDecimal`). Text, temporal, and converter fields ignore them. The `pattern` default applies to temporal fields.
4. A temporal field without `pic` and without `length`: `length` = the pattern length.
5. Collection direction: the explicit value, else `OUTPUT`.
6. `dependsOn`: the explicit value, else the member immediately before the collection in `order`.
7. Count field direction: if the count field has no explicit `direction`, use the direction of its collection.

Validation rules (all are `Diagnostic.Kind.ERROR` on the field element, message starts with the descriptor):
- operation class: not public, abstract, generic, a record, a non-static nested class, or without a public no-argument constructor;
- two operation classes with the same operation name in one compilation;
- an annotated `static` field; a field with both `@BookField` and `@BookCollection`; an explicit `direction` on an item field; one count field for two collections;
- `pic` that `PicParser` rejects (use the `PicSyntaxException` message);
- `pic` together with an explicit `length`, `scale`, `signed`, or `usage`;
- a non-temporal field without `pic` and without `length` (converter fields included);
- a text `pic` on a numeric Java type, or a numeric `pic` on `String`;
- duplicate `order` in the class hierarchy (superclass fields included);
- type × usage: `String` only `DISPLAY`; `int`/`Integer` length ≤ 9, `long`/`Long` length ≤ 18, scale 0; `BigDecimal` any usage, `scale ≤ length`; temporal types only `DISPLAY` and `length == pattern length` (build the formatter with the same rules as `Formats.of` and format a sample of the field type; an exception is an invalid pattern or a pattern that does not fit the type); `COMP` length ≤ 18; any unsupported type without a `converter` → error;
- `converter` class not public or without a public no-argument constructor; the `J` of `FieldConverter<J>` does not agree with the boxed field type (`Types.isSameType` after boxing);
- `length < 1`, `scale < 0`;
- missing getter or setter (only in the last round, see above);
- `@BookCollection`: field type not `List<X>`; `X` without a public no-argument constructor; `X` contains a `@BookCollection` (nested); `maxOccurs < 1`; `dependsOn` field missing, not `int/Integer/long/Long`, direction does not include the collection direction, or order is not before the collection;

### Task 10: Simulator transport

**Files:**
- Modify: `settings.gradle.kts` (include `bookmap-transport-simulator`)
- Create: `bookmap-transport-simulator/build.gradle.kts`, `SimulatorTransport.java`, `SimulatedOperation.java`, `SimulatedHandler.java`, `SimulatedAbend.java`
- Test: `bookmap-transport-simulator/src/test/java/pt/daaz/bookmap/simulator/SimulatorTransportTest.java`

**Interfaces:**
- Consumes: `Transport`, `BookRequest`, `BookCodecRegistry`, `CodecContext`, `BookCodec`, transport exceptions.
- Produces:
  - `@FunctionalInterface interface SimulatedOperation { byte[] handle(byte[] request); }`
  - `@FunctionalInterface interface SimulatedHandler<T> { void handle(T call); }` — `call` has the input fields. The handler sets the output fields on the same object.
  - `class SimulatedAbend extends RuntimeException { SimulatedAbend(String abendCode); String abendCode(); }`
  - `final class SimulatorTransport implements Transport { static Builder builder(); SimulatorTransport register(String operation, SimulatedOperation op); <T> SimulatorTransport register(Class<T> type, SimulatedHandler<T> handler); List<BookRequest> receivedRequests(); void clearReceivedRequests(); }`
  - `Builder { codecRegistry(BookCodecRegistry) /*default loadDefault()*/; charset(Charset) /*default IBM037*/; timeout(Duration) /*default 5 s*/; build(); }`

Behavior:
- The typed `register` gets the codec from the registry and uses the `operationName()` as the key. The typed level uses `codec.charsetName()` if it is not empty, else the simulator charset (the same rule as the client).
- `exchange` records the request first. An unknown operation → `OperationNotFoundException`.
- It runs the handler in a virtual thread and waits for `timeout`. A timeout → interrupt the thread (`future.cancel(true)`) and throw `TransportTimeoutException`.
- Exceptions from the handler: `SimulatedAbend` → `RemoteAbendException` with the same code. A `BookmapException` → unchanged. Any other exception → `TransportException` with the cause.
- The registrations and the request list are thread-safe.
